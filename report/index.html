On the record

What the model said, and when

Every forecast is saved before the games it predicts and never changed afterward. Each one is fingerprinted, checked by the test suite and pushed to GitHub with a timestamped tag. The model is frozen; new games only change the bracket situation, and each refresh adds forecasts it can be graded on. Retrospective rows were computed afterward for context and are never scored.

    How I got here

    The method, step by step

    The full log with every number is in LOG.md, and a partner review of the weak spots is in REVIEW.md. The core method was fixed before any 2026 odds were computed.

    1. Pulled every game since 2015

      regular-season and postseason results from the official MLB Stats API, plus the live bracket, rosters and announced starters. fetch_data.py, fetch_rosters.py

    2. Rated every team on runs, not wins

      A Poisson model gives each team an offense and a defense rating, adjusted for opponents and pulled toward average. Home field is set from actual home win rates ( between equal teams), because run totals understate it. model.py

    3. Tuned it on games it hadn't seen

      Fit through August, predict September, ten seasons over. Heavy shrinkage won, and weighting recent form didn't help. tune.py

    4. Graded it on 11 real Octobers

      Every playoff game and series from 2015–2025, each predicted using only that year's regular season. Also tested whether adjusting for each game's starting pitchers helps; it doesn't. backtest.py, sp_backtest.py

    5. Ran the live bracket

      Each series from its current state, then all four possible World Series, with home field set by MLB's tiebreak rules. predict.py

    6. Measured the uncertainty and tried to break it

      1,000 resampled seasons for the interval, eleven alternative setups, and a comparison against betting markets. sensitivity.py, market.py

    Limits

    What this model can't see

    • It rates teams on the full season. Injuries and October roster changes appear only in the roster-adjusted scenario, which is not backtested.
    • Bullpen fatigue, travel and day-to-day lineup choices are not modeled.
    • Market prices are a recorded snapshot from published articles, not a live feed, and they move by the hour.
